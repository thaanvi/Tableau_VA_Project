# Tableau Dashboard Project

## Dashboard Link
https://public.tableau.com/app/profile/thaanvi.sudarsan.meda/viz/Project_VA_17648122411530/Multi-StationEnvironmentalBehavior

## Project Overview
This project presents an interactive Tableau dashboard built to analyze and visualize key insights from the dataset.

## Key Insights
- It shows detailed short-term and long-term patterns in temperature and humidity
- They help users trace how environmental conditions evolve across seasons.
- This provides beyond time trends to highlight physical coupling between temperature and
humidity.

## Tools Used
- Tableau
- Tableau prep builder
- Excel / CSV
- Data Visualization
- Dashboard Design
